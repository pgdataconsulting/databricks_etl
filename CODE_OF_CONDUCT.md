# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion on the work, and
do not harass anyone. This applies to issues, pull requests, discussions and
any other space connected to the project.

To report behaviour that breaks these rules, contact the maintainers through
GitHub's [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
flow on the content in question, or privately through the repository's
**Security** tab if you would rather not reference it publicly. Reports are
handled confidentially.
